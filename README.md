# HomeMusic Android builds

Готовые debug-сборки Android-приложения HomeMusic для личной установки Frozen-12.

- Пакет: `app.homemusic.selfhost.debug` — ставится рядом с `app.homemusic`, данные не пересекаются.
- Каждый релиз содержит APK и архив исходников `android/` (GPL-3.0, форк Tempus).
- Основной репозиторий с серверной частью и полной историей приватный; соответствующий исходный
  код Android приложен к каждому релизу.

Это не официальная сборка автора HomeMusic/Tempus.
